# 坦克大战 - Battle City 🎮

一个基于经典 NES 游戏 **Battle City** 的网页版坦克大战游戏，使用纯 HTML/CSS/JavaScript 实现。

## 在线试玩

直接打开 `index.html` 即可在浏览器中游玩！

## 游戏截图

> 开始界面 → 选择关卡 → 操控坦克消灭敌人 → 保护基地！

## 操作方式

### ⌨ 键盘控制

| 按键 | 功能 |
|------|------|
| `↑` `↓` `←` `→` | 移动坦克 |
| `W` `A` `S` `D` | 移动坦克（备选） |
| `空格键` / `J` | 射击 |
| `Enter` | 开始游戏 / 重新开始 |

### 📱 触屏控制

在手机或平板上会自动显示虚拟方向键和射击按钮，可直接触屏操作。

## 游戏特性

- 🎯 **3 个关卡**，难度递增
- 🤖 **智能敌人 AI**，敌人会追踪玩家
- 🧱 **砖墙** - 可被子弹摧毁
- ⛓ **钢墙** - 子弹无法穿透
- 🦅 **基地（老鹰）** - 必须保护，被毁则游戏结束
- 💥 **爆炸特效** - 炫酷的粒子爆炸效果
- 🔄 **多生命系统** - 每次死亡后会在基地旁重生
- 🏆 **计分系统** - 每消灭一个敌人得 100 分

## 游戏规则

1. 消灭所有敌人即可通关
2. 保护基地（屏幕底部的老鹰）不被摧毁
3. 每条命被击中后会在基地旁重生
4. 所有命用完则游戏结束
5. 共有 3 个关卡等你挑战

## 技术实现

- **纯前端** - 无需任何服务器或依赖
- **Canvas 渲染** - 使用 HTML5 Canvas 绘制游戏画面
- **AABB 碰撞检测** - 精确的矩形碰撞检测
- **简单 AI 系统** - 敌人具备追踪和随机移动策略

## 如何运行

1. 下载或克隆本仓库
2. 双击打开 `index.html`
3. 按 `Enter` 开始游戏！

或使用本地服务器：

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

然后访问 `http://localhost:8000`
